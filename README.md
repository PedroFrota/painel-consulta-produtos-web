# Painel de Consulta de Produtos e Carrinho (HTML5 + CSS3 + JS)

Interface web desenvolvida com **HTML5 semântico**, **CSS3 (Flexbox/Grid)** e **JavaScript (ES6+)** puro para consulta rápida de catálogo de supermercado/atacado, busca em tempo real, filtro por categoria e simulação de carrinho de compras com cálculo automático de subtotais e descontos por atacado.

---

## Funcionalidades
- Busca instantânea por nome ou código do produto.
- Filtro dinâmico por categoria (`Mercearia`, `Laticínios`, `Bebidas`, `Limpeza`).
- Regra de **preço de atacado** aplicada automaticamente a partir de 5 unidades do mesmo item.
- Carrinho de compras interativo com adição, remoção e cálculo de valor total em tempo real.
